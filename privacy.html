Privacy Policy

Effective date: 27 October 2026

This policy describes how ClipForge, the tool that publishes the WhoFedLOL videos, handles data. ClipForge is a personal tool used only by the owner of the WhoFedLOL channel. It has no other users and does not offer sign-in to the public.

Google user data it accesses

ClipForge uses the YouTube API Services with the owner's own Google account, and only for the owner's own channel:

  • youtube.upload: to upload videos to the channel and set their thumbnails.
  • youtube.readonly: to read the channel ID and the status of the videos it uploaded (public, scheduled, deleted).

It does not access, collect or store data about any other Google user, viewer or subscriber.

How it is stored and shared

  • The OAuth token is stored only on the owner's private server, in a file readable only by the owner. It is never shared.
  • The IDs and status of the uploaded videos are kept in a local database on that server, to know what has been published.
  • No data is sold, shared with third parties or used for advertising.

ClipForge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube

ClipForge uses YouTube API Services. By watching the videos you are subject to the YouTube Terms of Service, and Google handles your data according to the Google Privacy Policy.

Revoking access

Access can be revoked at any time from Google Account → Third-party connections. Revoking it deletes nothing on the channel; ClipForge simply stops being able to upload.
